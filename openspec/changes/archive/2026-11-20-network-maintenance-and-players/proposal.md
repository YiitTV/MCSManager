# Proposal

## Why

Network operators need to coordinate proxy maintenance and manage players directly from the instance board.

## What Changes

- Add administrator controls for Velocity's Maintenance plugin, including its network-wide state and allowed players.
- Add Minecraft player counts and roster views to the grouped instance cards, with audited player actions on assigned game servers.

## Capabilities

### New Capabilities

- `network-maintenance` for Velocity maintenance controls.
- `minecraft-player-management` for player rosters and management actions.

### Modified Capabilities

## Impact

The board, panel authorization and operation logs, and daemon console and file readers gain new functionality. Existing instance configuration and dependencies suffice.
